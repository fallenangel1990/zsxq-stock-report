# 个股按板块分类展示 + 去掉评分阈值 — 设计文档

> 状态：已确认 ← 2026-08-04 用户审核通过
> 作者：Claude + chenlin
> 关联需求：将推荐的个股做具体板块的分类；个股不再设置阈值筛选

## 1. 背景与目标

当前股票报告存在两个问题：

1. **评分阈值截断候选池**：`_rebuild_report` 中 `passed = [s for s in enriched if score >= score_threshold]`（默认 ≥3.0），低于阈值的个股被整体丢弃。此前多次出现"分析 300 篇帖子没有一只个股入选"，阈值过严是根因之一。用户希望**个股不再按分数设置筛选门槛**，全部候选都展示，分数只作为板块内排序与标注。
2. **展示缺少板块视角**：当前"快速选股清单"是扁平的按推荐指数降序列表，无法快速按板块浏览机会。用户希望**按具体板块分类展示**个股。

**目标：**
- 移除评分阈值截断，所有 AI 提取出的候选个股都进入展示
- 新增"按板块分类"主清单，聚合每个板块下的全部个股
- 保留流动性与相关性风控（方案 3 已确认）

## 2. 范围（方案 3：去掉评分阈值 + 每板块上限，保留流动性/相关性）

**移除：**
- 评分阈值截断（`score >= score_threshold`，默认 3.0）
- 组合层每板块上限 `_apply_portfolio_constraints(max_per_sector)`

**保留：**
- `_apply_liquidity_filter`（流动性风控）
- `filter_by_correlation`（相关性风控，max_corr=0.7）
- 行业趋势检测、组合概览、交易员摘要、决策层级、护城河/三情景目标价等明细字段

## 3. 架构

改动集中在 `stock_extractor.py` 的 `_rebuild_report()`：

```
enriched（全部候选，不再按分数截断）
  → _apply_liquidity_filter（保留）
  → filter_by_correlation（保留）
  → 按板块分类聚合 → 生成"按板块分类"主清单
  → 其余明细章节照旧
```

新增一个小函数用于板块聚合：

```
def _group_stocks_by_sector(stocks: list[dict], trend_scores: dict) -> list[dict]:
    """按标准化板块名聚合个股，返回按板块内最高分降序的板块列表。

    每个板块：{sector, stocks(按 score 降序), heat/trend}
    无板块（sector 为空）的个股归入"未分类"分组，仍展示。
    """
```

## 4. 数据流与展示

### 4.1 筛选链路（Part 1，已确认）

`_rebuild_report` 中：
1. **移除** `passed = [s for s in enriched if s.get("score", 0) >= score_threshold]` → 直接用 `enriched` 作为展示池
2. **移除** `_apply_portfolio_constraints(passed, max_per_sector)` 调用
3. **保留** `_apply_liquidity_filter`、`filter_by_correlation`
4. 评分/推荐指数只作为排序和标注，不再是门槛

### 4.2 按板块分类主清单（Part 2，已确认）

新增章节，作为报告主清单，替换原扁平"快速选股清单"：

```
## 📋 按板块分类（全部候选，评分仅作板块内排序）

### 板块：AI/人工智能（板块内 N 只）
| 股票名称 | 机会类型 | 周期 | 当前市值 | 推荐指数 | 核心逻辑(截断) | 目标参考 | 风险点 |
|----------|----------|------|----------|----------|----------------|----------|--------|
| ...（按推荐指数降序） |

### 板块：半导体/芯片（板块内 M 只）
| ... |
```

**设计要点：**
- 板块名用现有 `_normalize_sector_name()` 标准化（config 的 `sector_aliases` 映射）
- 板块内个股按推荐指数降序；板块间按板块内最高推荐指数降序（或板块趋势分 `trend_scores`）
- 全部候选都展示，无分数门槛
- 同一股票若同时出现在量化+弹性，板块内去重合并为一条
- 无板块（sector 为空）的股票单独归入"未分类"分组，仍展示

### 4.3 既有章节去留（Part 3，已确认）

| 章节 | 处理 |
|------|------|
| 原"快速选股清单"扁平表 | **移除**（被按板块分类替代） |
| 一、有明确量化目标的股票（增强） | **保留**（完整护城河/三情景目标价明细） |
| 二、产业趋势中弹性最大的标的（增强） | **保留** |
| 三、细分板块机会（AI 原始板块表） | **保留**（板块级逻辑原文，与个股明细互补） |
| 🔥 行业趋势概览 | **保留** |
| 过滤概览/诊断 | **文案更新**：反映"不再按分数筛选"（如"全部候选 X 只，经流动性/相关性风控后展示 Y 只"） |

## 5. 错误处理

- 板块标准化未命中（`_normalize_sector_name` 返回空）：归入"未分类"分组，不丢票
- `trend_scores` 缺失：板块间排序退化为按板块内最高推荐指数
- 相关性过滤可能进一步减少展示数量：过滤概览如实反映

## 6. 测试

- 新增单元测试：`_group_stocks_by_sector` 聚合正确、板块内降序、去重合并、未分类分组
- 更新现有报告相关测试：移除评分阈值后全部候选进入展示
- 回归：`_rebuild_report` 不再因 `score_threshold` 截断产生空清单
